Documented patterns — copy, adapt, ship
Fragment swap
Server returns HTML, client staples it into a named slot. 80% of what most UIs do.
Skeleton loading
Placeholder shaped like real content. Swap in live data when fetch resolves. No state variable.
SSE streaming
Native EventSource — token-by-token AI output, live logs, long-running jobs. 3 lines.
DOM as state
One hidden div with data-* attrs survives every swap. No Redux, no Context, no Zustand.
Tab control
active class IS the selected tab. Content is a fetched fragment. No shared variable.
Modal API response
POST → server returns HTML fragment → rendered inside modal. No JSON shape to agree on.
Backend error handling
5xx returns an error fragment. Watchdog catches unreachable server. Two-tier, no try/catch sprawl.
Sidebar nav
Nav click swaps the content area. Active state on the button. Full-page feel, zero router.
